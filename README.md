# Flipkart Product Information Scraper

## About the Project
A Python-based web scraping project that extracts product information
from Flipkart search results. The project demonstrates how to send HTTP
requests, parse HTML content, and organize extracted information into
structured data.

## Features
- Extracts mobile product names
- Collects product descriptions, where available
- Extracts product prices and customer ratings, where available
- Parses HTML using BeautifulSoup
- Organizes collected data using Pandas
- Exports extracted information to CSV

## Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas
- HTML Parsing
